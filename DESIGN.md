# Handcrafted Haven - Design Theme

## Color Schema

### Primary Colors
- **Primary**: #8B5A2B (Warm Brown - artisan, craft, natural feel)
- **Secondary**: #2C3E50 (Deep Blue - professional, trustworthy)
- **Accent**: #D4A574 (Golden Tan - premium, handcrafted quality)

### Background Colors
- **Main Background**: #FAF8F5 (Warm off-white - natural, paper-like)
- **Card Background**: #FFFFFF (Pure white)
- **Section Background**: #F5F0EB (Light beige - craft paper feel)

### Text Colors
- **Primary Text**: #2C3E50 (Dark blue-gray)
- **Secondary Text**: #5D6D7E (Medium gray)
- **Accent Text**: #8B5A2B (Warm brown)

### UI Elements
- **Buttons**: #8B5A2B (Warm Brown) with hover #6D4A1F
- **Links**: #2C3E50 (Deep Blue)
- **Borders**: #E0D5C9 (Light beige-gray)
- **Success**: #27AE60 (Natural green)
- **Error**: #C0392B (Craft red)

## Typography

### Font Family
- **Primary**: 'Merriweather', Georgia, serif (elegant, artisan feel)
- **Secondary**: 'Open Sans', 'Segoe UI', sans-serif (clean, modern readability)

### Font Sizes
- **H1**: 3rem (48px)
- **H2**: 2.25rem (36px)
- **H3**: 1.75rem (28px)
- **Body**: 1rem (16px)
- **Small**: 0.875rem (14px)

### Font Weights
- **Bold**: 700
- **Semi-bold**: 600
- **Regular**: 400
- **Light**: 300

## Layout

### Container
- Max-width: 1400px
- Centered with auto margins
- Responsive padding

### Grid System
- Desktop: 4 columns for product cards
- Tablet: 2-3 columns
- Mobile: 1-2 columns

### Components
- **Product Card**: Image top, title, price, seller info, rating
- **Seller Profile**: Hero banner, bio, product grid
- **Navigation**: Sticky header with logo, search, cart, user menu
- **Hero Section**: Large banner with featured products and CTA

## Visual Elements

### Shadows
- **Card Shadow**: 0 4px 12px rgba(0,0,0,0.08)
- **Hover Shadow**: 0 8px 24px rgba(0,0,0,0.12)
- **Button Shadow**: 0 2px 8px rgba(0,0,0,0.15)

### Border Radius
- **Cards**: 8px (slightly rounded, elegant)
- **Buttons**: 4px (subtle, professional)
- **Inputs**: 4px
- **Avatars**: 50% (circular)

### Spacing
- **Section Spacing**: 5rem (80px)
- **Card Gap**: 2rem (32px)
- **Element Spacing**: 1.5rem (24px)

## Accessibility (WCAG 2.1 AA)

### Color Contrast
- All text meets minimum 4.5:1 contrast ratio
- Large text meets 3:1 contrast ratio
- Interactive elements have clear focus states

### Keyboard Navigation
- All interactive elements keyboard accessible
- Clear focus indicators
- Logical tab order

### Screen Reader Support
- Proper heading hierarchy
- Alt text for images
- ARIA labels for interactive elements

## Responsive Design

### Breakpoints
- **Mobile**: < 640px
- **Tablet**: 640px - 1024px
- **Desktop**: > 1024px

### Mobile Adaptations
- Single column layout
- Larger touch targets (min 44px)
- Simplified navigation
- Optimized images for mobile
