# Recipe Finder App - Design Theme

## Color Schema

### Primary Colors
- **Primary**: #FF6B35 (Orange - warm, appetizing color for food)
- **Secondary**: #004E89 (Deep Blue - contrast and trust)
- **Accent**: #F7C59F (Light Orange - highlights)

### Background Colors
- **Main Background**: #FAFAFA (Off-white)
- **Card Background**: #FFFFFF (White)
- **Section Background**: #F0F4F8 (Light blue-gray)

### Text Colors
- **Primary Text**: #1A1A1A (Dark gray)
- **Secondary Text**: #666666 (Medium gray)
- **Accent Text**: #FF6B35 (Orange)

### UI Elements
- **Buttons**: #FF6B35 (Orange) with hover #E55A2B
- **Links**: #004E89 (Blue)
- **Borders**: #E0E0E0 (Light gray)
- **Success**: #28A745 (Green)
- **Error**: #DC3545 (Red)

## Typography

### Font Family
- **Primary**: 'Inter', 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- **Headings**: 'Poppins', 'Segoe UI', sans-serif (more playful for food theme)

### Font Sizes
- **H1**: 2.5rem (40px)
- **H2**: 2rem (32px)
- **H3**: 1.5rem (24px)
- **Body**: 1rem (16px)
- **Small**: 0.875rem (14px)

### Font Weights
- **Bold**: 700
- **Semi-bold**: 600
- **Regular**: 400
- **Light**: 300

## Layout

### Container
- Max-width: 1200px
- Centered with auto margins
- Responsive padding

### Grid System
- Desktop: 3 columns for recipe cards
- Tablet: 2 columns
- Mobile: 1 column

### Components
- **Recipe Card**: Image top, title, tags, favorite button
- **Search Bar**: Large, prominent at top
- **Navigation**: Sticky header with logo and menu
- **Modal**: Centered overlay for recipe details

## Visual Elements

### Shadows
- **Card Shadow**: 0 2px 8px rgba(0,0,0,0.1)
- **Hover Shadow**: 0 4px 16px rgba(0,0,0,0.15)
- **Button Shadow**: 0 2px 4px rgba(0,0,0,0.2)

### Border Radius
- **Cards**: 12px
- **Buttons**: 8px
- **Inputs**: 6px
- **Tags**: 16px (pill shape)

### Spacing
- **Section Spacing**: 4rem (64px)
- **Card Gap**: 2rem (32px)
- **Element Spacing**: 1rem (16px)

## Responsive Design

### Breakpoints
- **Mobile**: < 768px
- **Tablet**: 768px - 1024px
- **Desktop**: > 1024px

### Mobile Adaptations
- Single column layout
- Smaller font sizes
- Touch-friendly buttons (min 44px height)
- Collapsible navigation
