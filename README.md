# Recipe Finder App

A React + Vite application for searching recipes, viewing instructions, and managing favorite recipes.

## Project Overview

This application allows users to:
- Search recipes by name or ingredients
- View detailed recipe instructions and ingredients
- Save favorite recipes to localStorage
- Create shopping lists from recipe ingredients

## Tech Stack

- React
- Vite
- TheMealDB API
- CSS/Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
